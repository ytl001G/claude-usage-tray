# 설계 문서

Claude Usage Tray v1.2.0의 동작과 구조입니다. 사용법은 [README](../README.md), 설정 파일과 동작 원리 요약은 [ADVANCED.md](ADVANCED.md)에 있습니다.

## 1. 목표

- 화면 구석에 Claude 플랜의 **주간 사용률**(%)을 항상 보여준다.
- 지금 속도로 쓰면 **언제 100%가 되는지**, 그게 리셋보다 먼저인지 알려준다.
- Claude Code를 켜 두지 않아도 스스로 갱신한다.
- 쓰고 있는 PC를 방해하지 않는다: 포커스를 가져가지 않고, 작고, 소리가 없다.

## 2. 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 시작점. 중복 실행 방지, 시작 프로그램 등록 동기화, 조회 스레드, 메뉴 동작 연결 |
| `tray/usage_api.py` | 로그인 정보 읽기, 사용량 API 호출과 응답 해석, 토큰 갱신, 로그인 콘솔 |
| `tray/controller.py` | 조회 1회: 갱신 정책 → 사용량 → 기록·예측·알림 → 화면용 `View` |
| `tray/history.py` | 이번 주·지난주 기록, 소진 예측 |
| `tray/credit.py` | (선택) claude-mode가 남긴 파일로 API 크레딧 잔액 추정 |
| `tray/alerts.py` | 알림을 띄울지 판단, 이미 띄운 것은 `state.json`에 기억 |
| `tray/render.py` | 모든 화면을 Pillow로 그림 (위젯 3종, 메뉴, 알림 창) |
| `tray/ui.py` | Tk 창, 크기 전환, 드래그, 메뉴, 알림 배치 |
| `tray/winsys.py` | Win32: DPI, 모니터 작업 영역, 포커스, 전체 화면 감지, 시작 프로그램 등록 |
| `tray/config.py` | 경로, 설정 읽기·검증·저장 |
| `tray/text.py` | 날짜·시간 한국어 표현 |
| `tools/` | `build.py`(exe와 SHA-256), `screenshot.py`(README 그림), `subset_fonts.py`(폰트 줄이기) |

- **스레드:** Tk는 메인 스레드에서만 다룬다. 조회 스레드는 `UI.post()`로 메시지만 보낸다.
- **조회 주기:** `poll_minutes`(기본 5분). 새로고침이나 로그인이 끝나면 바로 다시 조회한다.
- **배포:** PyInstaller 단일 `.exe` (Python 3.11, tkinter, Pillow). 트레이 아이콘은 쓰지 않는다.

## 3. 데이터

### 사용량 API
- `GET https://api.anthropic.com/api/oauth/usage`
- 헤더: `Authorization: Bearer <토큰>`, `anthropic-beta: oauth-2025-04-20`
- Claude Code 내부에서 쓰는 비공개 API라 예고 없이 바뀔 수 있다.

| 필드 | 쓰임 | 필수 |
|---|---|---|
| `seven_day.utilization`, `resets_at` | 주간 사용률(정수 %)과 리셋 시각 | 예 |
| `five_hour.utilization`, `resets_at` | 5시간 한도 | 아니오 |
| `seven_day_breakdown.rows` | 사용처 비중 (Claude Code, 채팅 등) | 아니오 |
| `limits[]` 중 `kind: weekly_scoped` | 모델별 주간 한도 | 아니오 |

- 필수가 아닌 필드는 없거나 형식이 바뀌어도 그 항목만 건너뛴다.
- 이번 주에 아직 안 써서 `resets_at`이 없으면 "이번 주 사용 없음"으로 표시하고 기록하지 않는다.
- 리다이렉트는 따라가지 않는다 (토큰이 다른 호스트로 넘어가지 않게).

### 로그인 정보
- `CLAUDE_CONFIG_DIR`(없으면 `~/.claude`)의 `.credentials.json` → `claudeAiOauth`
- **읽기만 한다.** 앱은 이 파일을 절대 수정하지 않는다.

### 예비 데이터 (선택)
- API를 못 읽었을 때 같은 폴더의 `usage-snapshot.json`이 마지막 값보다 새로우면 쓴다. Claude Code 상태줄 스크립트가 이 파일을 남기는 환경에만 해당한다.

## 4. 토큰 갱신

접속 토큰은 약 8시간, 로그인 자체는 약 4주 뒤 만료된다. 접속 토큰은 Claude Code가 직접 갱신하게 한다.

```
claude -p "." --model haiku --system-prompt "Reply with one character." --tools "" --strict-mcp-config --setting-sources "" --disable-slash-commands --no-session-persistence --output-format json
```

| 규칙 | 내용 |
|---|---|
| 언제 | 조회가 **401**이고, 저장된 토큰이 이미 만료(또는 60초 이내, 또는 만료 시각 모름)일 때만 1회 |
| 하지 않을 때 | 유효한 토큰에 대한 401, 403, 로그인 자체가 만료됐을 때 |
| 성공 판정 | 갱신 후 저장된 토큰이 실제로 바뀌었을 때 (값이 다르거나 만료 시각이 늘어남) |
| 간격 | 최소 30분. 실패가 이어지면 30분 → 1시간 → 2시간 → … 최대 8시간. 조회가 성공하면 초기화 |
| 비용 | 1회 약 580 입력 / 3 출력 토큰. 정상이면 하루 2~3회, 끝없이 실패해도 하루 최대 7~8회 |
| 실행 환경 | 숨긴 창, 임시 폴더에서 실행. `ANTHROPIC_API_KEY` 등 인증 환경변수는 빼고 넘긴다 (API 과금 방지) |
| 시간 초과 | 180초 뒤 `taskkill /T`로 프로세스 트리 전체 종료 |
| 실행 파일 | `claude`는 PATH의 절대 경로에서만 찾는다 (현재 폴더 제외) |

로그인이 만료되면 사용자가 [로그인]을 눌러야 한다. 이 버튼은 **보이는 콘솔 창**에서 `System32\cmd.exe`로 `claude auth login`을 실행한다. 브라우저에 나온 코드를 붙여넣어야 하므로 숨겨서 실행할 수 없다. 콘솔이 닫히면 바로 다시 조회한다.

## 5. 기록과 예측

### 기록 (`history.jsonl`)
- 한 줄: `{"at": 초, "week": %, "five": %, "resets": 리셋 시각(10분 단위)}`
- 값이 바뀔 때, 그리고 바뀌지 않아도 1시간마다 1줄을 남긴다.
- 이번 주와 지난주만 보관한다 (이번 주 시작 − 7일 − 6시간보다 오래된 줄 삭제). "지난주"는 이번 주보다 앞선 가장 최근 리셋 시각의 기록이다.
- 깨진 줄은 무시하고, 쓰기 실패는 로그만 남긴다. 앱을 오프라인에서 시작하면 마지막 기록을 오래된 데이터로 보여준다.
- 이미 리셋이 지난 주의 값은 현재 값으로 쓰지 않고 "새 주 0%, 오래된 데이터"로 보여준다.

### 예측
- **예측 속도는 이번 주 평균 하나다:** 이번 주 누적 사용률 ÷ 주 시작 후 지난 시간 (주 시작 0% 기준이라 기록 없이도 계산). 그래프 점선, 판정 문구, 색, 알림이 모두 이 속도를 따른다.
- 최근 24시간 속도(구간 전체 선형 회귀, 측정이 3시간 이상 걸쳐 있을 때)는 참고용으로 판정 아래 줄에만 표시한다.
- 예상 소진 시각 = 측정 시각 + (100 − 현재%) ÷ 평균 속도. 데이터가 오래돼도 측정 시각 기준으로 계산한다.
- 리셋 후 12시간 동안은 "예측 준비 중"이다.

| 상태 | 조건 | 판정 문구 |
|---|---|---|
| 준비 중 | 리셋 후 12시간 미만 | 예측 준비 중 · 몇 시간 뒤 표시 |
| 여유 | 리셋 후 12시간 넘어서야 소진 | 리셋까지 여유 · 예상 ○○% |
| 아슬아슬 | 리셋 후 12시간 안에 소진 | 아슬아슬 · 리셋 때 약 ○○% |
| 소진 | 리셋 전에 소진 | ! 이 속도면 ○○ 소진 |
| 한도 도달 | 100% | ! 주간 한도 소진 · ○○ 리셋 |

## 6. 위젯

### 크기 3단계 (사라지는 상태는 없음)

| 크기 | 내용 | 크기 (1배) |
|---|---|---|
| 아주 작은 아이콘 | 주간 %만, 2배 굵기 픽셀 숫자 | 약 50×26 |
| 작은 막대 (기본) | 주간 % + 게이지, 리셋 시각, 판정 한 줄 | 300×76 |
| 큰 화면 | 위 내용 + 그래프, 5시간 한도, 사용처·데이터 시각 | 340×238 |

- 인증에 실패했거나 로그인 만료 3일 전부터는 맨 위에 "! 로그인 필요 / 로그인 만료 D-n [로그인]" 줄이 생긴다 (+21).
- 기본 위치는 화면 오른쪽 아래, 작업 표시줄 바로 위. 크기가 바뀔 때 오른쪽 아래 모서리를 기준으로 커지고 줄어든다.
- 마지막 평소 크기(작은 막대 또는 아이콘)와 위치를 저장한다.

### 조작

| 동작 | 결과 |
|---|---|
| 막대·큰 화면 더블클릭 | 작은 막대 ↔ 큰 화면 |
| 아이콘 한 번 클릭 | 작은 막대로 펼침 |
| 막대·큰 화면 한 번 클릭 | 아무 일 없음 |
| 마우스 휠 ↑ / ↓ | 한 단계 커짐 / 작아짐 (한 번 굴릴 때 한 단계) |
| `–` / `▾` `▴` 버튼 (15×15) | 아이콘으로 / 큰 화면 열기·닫기 |
| 큰 화면 바깥 클릭 | 마지막 평소 크기로 |
| 드래그 | 이동. 화면 가장자리·작업 표시줄에서 16픽셀 이내면 붙음 |
| 오른쪽 클릭 | 도트 메뉴 |

- 아이콘을 더블클릭하면 막대에서 멈춘다 (펼친 직후 같은 더블클릭의 두 번째 클릭은 무시).
- 메뉴를 닫은 클릭은 닫기만 한다.

### 오른쪽 클릭 메뉴
지금 새로고침 / 크게 (그래프) / 작은 막대 / 아주 작게 (아이콘) / 위치 초기화 / 설정 파일 열기 / Windows 시작 시 실행 ✓ / 종료 (버전)

- 도트로 직접 그리고 포커스를 가져가지 않는다. 마우스를 올린 항목은 주황색으로 강조한다.
- 커서가 항상 메뉴 안쪽에 오도록 열린다 (오른쪽 아래 구석에서는 왼쪽 위로). 바깥을 클릭하면 닫힌다.

### 상태 색

| 색 | 조건 |
|---|---|
| 주황 (정상) | 아래에 해당 없음 |
| 노랑 (주의) | 80% 이상, 또는 아슬아슬 |
| 빨강 (위험) | 95% 이상, 소진 예상, 한도 도달 |
| 회색 (오래됨) | 15분 이상 새 데이터 없음 |

### 큰 화면의 그래프와 하단 줄
- 주황 실선은 이번 주 기록, 흐린 선은 지난주, 점선은 예측, 빨간 점은 100% 도달 예상 지점, 흰 점은 마지막 측정이다.
- 첫 측정 전 구간(주 중간에 처음 켰을 때)은 0%에서 첫 측정까지 흐린 점선이다.
- 배경의 어두운 막대는 3시간마다 쓴 사용량(누적 그래프를 구간별로 나눈 값)이다. 가장 많이 쓴 구간이 그래프 높이의 절반이 되게 맞추고 숫자는 따로 표시하지 않는다. 측정 간격이 2시간을 넘는 구간(앱이 꺼져 있던 때, 첫 측정 전)은 늘어난 양을 고르게 나눈 추정치라 테두리만 그린다.
- (선택) 5시간 한도 아래 API 크레딧 줄: `~/.claude/claude-mode/credit.json`이 있을 때만 "API $잔액, 게이지(월 지급액 대비), 이번 달 사용, 다음 충전일"을 보여준다 (+16). 잔액은 그 파일의 콘솔 잔액에서 이후 `usage.jsonl` 비용을 뺀 추정치이고, 충전일이 지나면 월 지급액부터 다시 센다. 20% 미만 노랑, 5% 미만 빨강. 계산은 `tray/credit.py`, 형식은 [ADVANCED.md](ADVANCED.md#동작-원리).
- 하단 줄: 사용처 비중 → 로그인 D-day → 모델별 한도 순서로, 안 들어가는 항목은 통째로 생략한다. 데이터가 오래되면 실패 이유와 "! N분/시간/일 전 데이터"를 보여준다.

### 방해하지 않기
- 위젯, 메뉴, 알림 창은 모두 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW` 창이다. 포커스를 가져가지 않고 작업 표시줄에 나타나지 않는다.
- Tk를 만들 때 Windows가 숨은 창에 포커스를 주면, 원래 창에 즉시 돌려준다.
- PC 잠금, 화면 보호기, 전체 화면(게임·영상·발표)일 때는 위젯을 숨기고 알림을 미룬다. 2초마다 확인한다.

### 배율과 모니터
- 도트가 뭉개지지 않도록 정수 배율만 쓴다: 화면 배율 175% 미만은 1배, 175% 이상 2배, 275% 이상 3배.
- 위젯이 있는 모니터의 작업 영역과 DPI를 기준으로 그리고 배치한다.

## 7. 알림

화면 오른쪽 아래, 위젯 바로 위(위젯이 화면 위쪽에 붙어 있으면 바로 아래)에 뜨는 240×64 창이다. 위젯을 가리지 않는다. Windows 알림 센터는 쓰지 않는다.

| 상황 | 반복 |
|---|---|
| 주간 80 / 90 / 95% 도달 (여러 개를 한 번에 넘으면 가장 높은 것만) | 주마다 각 1회 |
| 리셋 전 소진 예상으로 바뀜 | 하루 최대 1회 |
| 5시간 한도 90% | 5시간 구간마다 1회 |
| 로그인 만료 3일 전 | 하루 1회, 마지막 날은 3시간마다, 만료 후에는 하루 1회 |
| 조회 3회 연속 실패 | 하루 1회 (로그인 만료 중에는 생략) |
| [로그인]을 눌렀는데 `claude`가 없음 | 누를 때마다 |

- % 도달과 소진 예상이 같은 순간이면 하나로 합친다.
- 대기 중인 알림은 제목별 최신 1개, 최대 3개만 유지한다.
- 8초 뒤 사라지고, 마우스를 올리면 유지된다. 클릭하면 위젯을 큰 화면으로 열고, ✕는 닫기, [로그인]은 로그인 콘솔을 연다.
- 인증 문제일 때만 [로그인] 버튼을 보여준다 (네트워크 문제에는 "인터넷 연결 확인").

## 8. 오류 처리

| 상황 | 동작 |
|---|---|
| 인터넷 끊김 | 마지막 값 유지, 15분 뒤 회색 + "! N분 전 데이터" + 이유 |
| 응답 형식 변경 (`seven_day` 없음 등) | 조회 실패로 처리, 예비 데이터가 있으면 사용 |
| 토큰 만료 | 4번 규칙으로 갱신, 실패하면 "! 로그인 필요 [로그인]" |
| 로그인 만료 | "로그인 만료 · 다시 로그인 필요" + [로그인] |
| 로그인 파일 없음 | "Claude Code 로그인 필요" + [로그인] |
| 파일 쓰기 실패 | 로그만 남기고 계속 동작 |
| 화면 처리 중 예외 | 로그만 남기고 계속 동작. 종료 요청은 항상 처리 |
| 두 번째 실행 | 이미 실행 중이면 조용히 종료 |

## 9. 설정과 파일

- 설정 항목과 범위는 [ADVANCED.md](ADVANCED.md#설정-파일)에 있다. 모든 값은 형식과 범위를 검사하고, 읽을 수 없는 설정 파일은 덮어쓰지 않는다.
- 앱이 쓰는 곳은 두 군데뿐이다.
  - `%APPDATA%\ClaudeUsageTray\`: `config.json`, `history.jsonl`, `state.json`, `app.log`(최대 약 400KB)
  - `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`의 `ClaudeUsageTray` 값 (시작 시 실행이 켜져 있고 exe로 실행할 때만)
- 설정과 상태 파일은 임시 파일에 쓴 뒤 바꿔 넣는다 (중간에 꺼져도 깨지지 않게).
- 앱은 실행 직후 작업 폴더를 데이터 폴더로 바꾼다 (받은 폴더의 파일이 실행되지 않게).

## 10. 보안

- 토큰은 `api.anthropic.com`에만 보낸다. 화면, 로그, 파일 어디에도 남기지 않는다. 로그에는 오류 종류와 HTTP 상태 코드만 남긴다.
- `shell=True`를 쓰지 않는다. 외부 실행은 `claude`(PATH의 절대 경로), `System32\cmd.exe`, `System32\taskkill.exe`뿐이다.
- 텔레메트리는 없다. 넣어야 할 비밀값이 없어서 `.env`를 쓰지 않는다.
- 배포 exe는 서명되지 않았다. 대신 SHA-256을 함께 배포한다.

## 12. 테스트

- `pytest`로 실행한다. 테스트는 네트워크, 실제 로그인 파일, `claude` 명령, 레지스트리를 쓰지 않는다 (네트워크 연결 시도는 테스트에서 차단).
- **로직:** API 응답 해석, 갱신 정책(하루 동안의 호출 횟수 포함), 기록과 예측, 알림, 설정 검증, 위치·자석·메뉴 배치 계산.
- **화면:** 모든 상태의 그림이 팔레트 색만 쓰는지, 모든 글자가 폰트에 있는지.
- **실제 창:** Tk 창을 띄워 크기 전환, 더블클릭, 드래그와 자석, 메뉴, 알림 배치, 포커스를 가져가지 않는지 확인한다. 실제 마우스와 전체 화면 상태는 가짜 값으로 바꿔서, 테스트 중에 PC를 써도 결과가 같다.
- **저장소:** 추적되는 파일에 이메일·개인 경로·토큰이 없는지, 커밋 작성자가 익명인지, `.env`가 없는지, 모든 `.py`가 컴파일되는지, 문서의 굵은 글씨와 링크가 GitHub에서 제대로 보이는지.

## 13. 한계

- 비공개 API를 쓰므로 Anthropic이 바꾸면 동작하지 않을 수 있다.
- 사용률은 서버 값 그대로 정수 %이다.
- Claude Code 로그인이 약 4주마다 만료되어 다시 로그인해야 한다.
- Windows 10/11 전용이다. 화면 배율 125%와 150%에서는 1배로 그려져 다른 글자보다 조금 작다.
